# Economía Familiar

Aplicación web para gestionar una economía familiar compartida.

## Stack

- Next.js + TypeScript
- Tailwind CSS
- Recharts
- Supabase (siguiente fase)
- Vercel (despliegue)

## Ejecutar

```bash
npm install
npm run dev
```

Abrir http://localhost:3000
